# Evidence Bundle

These are deterministic simulated transfer runs generated by `python scripts/generate_evidence.py`. They exercise the actual `DiscoveryAgent`, `ReplayEngine`, `RunRecorder`, and artifact validator using fake model/browser boundaries. No live ParaBank session or funds transfer occurred.

- `run_transfer-demo-discovery.artifact.json`: version 1.1 transfer workflow with ordered steps, typed inputs, approval checkpoint, and success condition.
- `run_transfer-demo-discovery.jsonl`: discovery actions, artifact persistence, and successful simulated transfer result.
- `run_transfer-demo-replay-success.jsonl`: successful artifact replay and returned `transfer_status` output.
- `run_transfer-demo-replay-bad-account.jsonl`: replay with synthetic unknown destination `SIM99999`, reported as `business_outcome/account_not_found` rather than a crash.

All account identifiers are synthetic (`SIM00001`, `SIM00002`, `SIM99999`) and are redacted in the logs. To regenerate without overwriting these files, use another prefix, for example `python scripts/generate_evidence.py --run-prefix transfer-demo-2`.
